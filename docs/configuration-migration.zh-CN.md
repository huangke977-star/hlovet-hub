# HLOVET 配置迁移

后台“系统运行概览”中的“系统配置迁移”用于在不迁移用户和文章内容的情况下，把一套站点配置带到另一台服务器。

## 会迁移什么

- 站点名称、主题、通知模板和功能开关；
- SMTP、Turnstile、Google OAuth 的配置；
- 主 AI 与 Embedding、OCR、转写、图片生成能力配置；
- 主 AI 和各项能力的备用模型配置及其加密密钥；
- 数据库备份策略和存储扫描策略；
- 文章分类、标签以及审核策略；
- 审计留存策略。

## 不会迁移什么

- 用户、密码、通行密钥、双因素凭据和登录设备；
- 文章、评论、点赞、收藏、聊天和通知；
- Redis 会话和限流状态；
- AI 对话、AI 用量历史和知识库文章索引；
- 用户头像、文章图片和聊天附件。

## 操作步骤

1. 在旧服务器以超级管理员进入“后台管理 -> 系统运行概览”。
2. 找到“系统配置迁移”，点击“导出配置包”。
3. 将下载的 JSON 文件通过安全方式保存，不要提交到 GitHub 或发送到公开聊天。
4. 在新服务器先完成一次全新部署，执行数据库迁移和种子数据初始化。
5. 新服务器的 `.env` 必须填写合法的 `BACKUP_ENCRYPTION_KEY`。如果要保留配置包中的 SMTP、Google、AI、OSS/R2 密钥密文，必须使用旧服务器的同一个 `BACKUP_ENCRYPTION_KEY`。
6. 在新服务器以超级管理员打开同一页面，点击“导入配置包”并选择 JSON 文件。
7. 导入后按新域名检查 `SITE_DOMAIN`、`WEB_ORIGIN`、Passkey Origin、Google 回调地址、Turnstile 域名和 TURN 配置。
8. 用新服务器的新管理员账号验证站点、后台、AI 配置页面和安全配置页面。

## Embedding 未配置时

导入配置包不会自动调用任何 AI 服务。知识库仍可以建立文本切片并使用关键词检索；配置 Embedding 后，在 AI 配置页点击“建立/刷新索引”即可补充向量。

## 安全注意

配置包中的 Secret 是服务端密文，不是明文，但仍属于敏感文件。导出后应限制文件访问权限，并在迁移完成后删除临时副本。新域名不能直接复用旧的 Passkey Origin 和 Google OAuth 回调地址。
