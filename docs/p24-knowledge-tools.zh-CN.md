# P24 知识与智能工具使用说明

## 当前状态

P24 已完成代码、数据库迁移、AI 专项测试和前端构建。P24 不要求 OSS/R2，也不在服务器上运行本地模型、Ollama、向量数据库或其他常驻 AI 服务；当前使用外部模型 API，未配置的能力保持关闭。

## 用户入口

登录用户从顶部导航进入“AI 助手”，页面包含历史对话、问答区和受控工具。AI 请求只有在后台启用并配置完整的外部模型后才会发送。

受控工具下方的“媒体工具”提供用户侧入口：图片 OCR、语音转文字和图片生成分别受后台能力开关控制。未配置的能力会显示为“未配置”并保持不可点击；已完成的任务会按当前账号保存到最近任务列表。OCR/转写结果只在所属账号的详情接口中读取，生成图片通过登录态保护的图片接口返回，不会把图片 Base64 放进列表响应。

问答会根据问题搜索当前账号可见的站内文章，也支持在文章、专题或合集中发起上下文问答。文章权限会在服务端先过滤，再把允许的正文片段提交给模型。配置 Embedding 后会使用向量相似度与关键词混合检索；未配置时仍建立文章片段并降级为关键词检索。积分资源等受保护内容仍沿用文章接口的脱敏规则，不会因为 AI 入口而绕过权限。

上下文使用近期消息加自动摘要：达到后台设置的阈值后，系统会压缩旧消息并保留目标、事实、来源和未完成事项；自动压缩失败不会阻塞当前对话。后台的“上下文保留天数”只限制发送给模型的历史和摘要，不会删除用户在对话页面中可查看的历史记录；修改该天数时会立即清空已有摘要，让新的窗口从合规范围内重新累计。

## 受控工具

| 工具 | 作用 | 写入权限 |
| --- | --- | --- |
| 我的积分与成长 | 查看自己的积分、经验、等级和近期账本 | 只读 |
| 我的待办 | 汇总自己的未读通知和待处理入口 | 只读，不自动标记 |
| 我的订阅 | 查看自己订阅的作者、专题和合集 | 只读 |
| 我的收益 | 查看自己的待结算、已结算和退款收益 | 只读 |
| 我的文章状态 | 查看自己的草稿、发布和审核状态 | 只读 |
| 搜索可见文章 | 只搜索当前账号有权限查看的文章 | 只读 |
| 读取文章上下文 | 读取可见文章正文作为问答来源 | 只读 |
| 总结专题/合集 | 汇总当前账号可访问的专题或合集文章 | 只读 |
| 解释后台概况 | 管理员查看自己有权限的运营汇总 | 只读 |
| 创建文章草稿 | 根据标题和正文准备一份草稿预览 | 必须人工确认 |

创建草稿不会直接写入文章。系统先保存待确认的预览，生成一次性短期确认令牌；用户点击“确认创建”后才调用现有文章创建流程。令牌只保存 SHA-256 摘要，默认十分钟过期。

## 后台入口

超级管理员进入“后台管理 -> AI 配置”：

- 配置供应商、接口地址、模型和 API Key；
- 设置全站/单用户并发、输出上限、超时和每日请求上限；
- 查看服务器推荐并发、连接测试、token/费用统计和脱敏调用记录；
- 查看“工具审计”，只展示工具名称、账号、状态、确认要求和时间，不展示输入参数、输出正文或 API Key。
- 配置 Embedding、OCR、语音转文字和图片生成的独立开关、供应商、模型、并发、每日上限、月度预算和单价；媒体接口未配置时不会调用外部服务。
- 主 AI 和每项能力都支持可选备用模型，并可分别填写备用模型的输入/输出价格。只有超时、暂时无法连接、429 或 5xx 才会自动切换；主模型失败和备用模型结果会分别记录，并按实际命中的模型估算费用，参数或权限错误不会被重试。
- 查看知识库文章索引状态、片段数和向量数，并批量或单篇重建索引。
- 查看能力成功率、失败率、Token、费用估算以及用户对回答的有帮助/没帮助反馈。DeepSeek 和常见 OpenAI 兼容模型命中精确名称时，价格区会出现可手动套用的官方价格参考；价格会变化，最终以供应商账单为准。

普通管理员不能读取或修改 AI 配置，也不能查看工具审计。

## 安全边界

- API Key 只在服务端加密保存，不返回浏览器；
- 每次对话和工具调用都绑定当前账号，不能读取其他账号的对话或个人数据；
- API 采用固定工具白名单，未知工具直接拒绝；
- 暂未开放删除、发布、改分、改配置等高风险 AI 操作；
- 调用日志只保留状态、耗时、token、模型和安全错误摘要，不保存提示词与生成正文；
- 远程模型的费用、服务条款和数据处理范围仍由管理员按供应商规则确认。

## 验证步骤

1. 用超级管理员进入“后台管理 -> AI 配置”，保存未启用配置，确认不会发起 AI 请求。
2. 填写外部模型地址、模型和 API Key，保存后点击“测试连接”，在“调用记录”看到成功或脱敏失败记录。
3. 启用 AI 后进入“AI 助手”，提问一篇公开文章，确认回答显示来源链接。
4. 用无权限文章或其他账号的私有文章提问，确认 AI 不会返回不可见内容。
5. 在“受控工具”执行个人积分、订阅或文章状态查询，确认结果只属于当前账号，并在后台“工具审计”出现记录。
6. 准备文章草稿，确认页面先出现预览；不点确认时数据库不创建文章，点击确认后才出现草稿。
7. 用普通管理员访问 `/admin/ai`，确认页面显示无权访问；用超级管理员确认可以查看配置和审计。
8. 在后台 AI 配置中点击“建立/刷新索引”，确认文章片段和索引状态出现；单篇点击刷新图标只重建对应文章，已删除或未发布的文章会清理失效索引。
9. 在 AI 回复下点击点赞或点踩，刷新页面后确认当前回复保留选中状态，并在后台使用量与质量区域看到反馈统计。
10. 在能力卡片关闭 OCR、语音或图片生成后调用对应接口，确认页面提示未配置；重新启用并填写供应商配置后，再用真实样本验证媒体任务状态和用量记录。
11. 在主模型名称中选择 `deepseek-chat`、`deepseek-reasoner`、`gpt-4o-mini`、`gpt-4o` 或 `o3-mini`，确认价格区出现魔法棒图标；点击后检查币种、输入价和输出价被填入，再按当前供应商账单复核后保存。
12. 在“AI 助手”的“媒体工具”中确认未配置的 OCR、语音转文字和图片生成按钮不可点击；配置真实供应商后上传图片或音频、提交图片描述，确认任务状态、结果和最近任务列表按当前账号显示。生成图片历史通过任务详情加载，不应在任务列表中出现 Base64 内容。

## 资源边界

当前向量保存在 MySQL JSON 字段中，检索最多读取有限数量的候选片段并在 API 进程内计算相似度，适合当前小规模服务器。文章量明显增长后，再考虑迁移到专用向量数据库；不建议在约 2 vCPU、约 1.6 GiB 内存的服务器上部署本地大模型或常驻向量服务。OCR、语音和图片生成目前使用同步接口，单次请求受超时、并发、文件大小和预算限制保护。
