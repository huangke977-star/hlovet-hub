## 当前包含

- 首页推荐与今日灵感入口
- 登录后的首次兴趣引导：最多选择 3 个专题和 6 位创作者，也可以暂时跳过
- 发现、搜索入口、推荐专题和合集
- 首页全站搜索：文章、用户、导航、工具、专题、合集、群聊和公告，支持分类筛选、分页、热门搜索、搜索历史和排序
- 写作入口、真实草稿列表和文章编辑器（站点分类/标签、Markdown/HTML、附件、自动保存、预览、版本历史、发布检查）
- 文章模板管理：创建、编辑、删除和在新建文章中直接套用模板
- 消息、未读提醒和聊天列表
- 消息通知频道设置：系统/订阅/互动推送开关、订阅日报开关，以及清除并隐藏旧频道通知；最近通知支持单条删除
- Android 系统通知：未配置 Firebase 时使用登录后的前台未读通知轮询；配置 Firebase 后注册 FCM token，后台数据消息会复用同一套聊天、文章、评论和删除内容跳转
- 好友与请求：好友申请、陌生人消息请求、好友删除/拉黑/解除屏蔽、用户搜索和直接打开聊天
- 聊天语音消息录制（最长 5 分钟、AAC/M4A、发送前可取消）、附件选择与上传、图片缩略图/预览；聊天与评论共用行内音视频播放、暂停、进度和重试，仍保留文件下载、系统打开与另存为；受保护附件按账号隔离缓存，媒体缓存上限 32 MB
- 聊天消息操作：引用回复、@候选与上下键选择、消息转发、群消息置顶/取消置顶、群消息举报、撤回、单向/双向删除，以及清空或隐藏当前会话
- 直接会话语音/视频通话：应用级来电监听、麦克风/摄像头权限、来电接听/拒绝、SDP/ICE 信令、静音、摄像头开关和切换；真实双账号通话仍需在两台已登录设备上验收
- 消息通知点击路由：聊天 @ 通知定位消息，文章/评论通知打开对应文章，已删除内容提示后不跳转
- 消息深链支持 `/messages?conversation={conversationId}` 和 `/messages?conversation={conversationId}&messageId={messageId}`：进入原生会话并定位目标消息；未登录时暂存目标，登录成功后自动继续
- 文章编辑与管理员预览入口支持 `/articles/edit/{id}` 和 `/articles/preview/{id}`：前者登录后直接进入原生编辑器，后者通过管理员接口进入只读文章状态预览；未登录时会暂存目标，完成登录后自动继续
- 文章详情正文使用受限 WebView 渲染 Markdown/HTML 的标题、段落、表格、任务列表、代码块、引用、链接、图片、音频、视频和积分资源区块；多语言代码块使用 APK 内置 `highlight.js` 离线着色，正文 HTML 会经过白名单清洗，正文媒体使用账号隔离的 32 MB 本地缓存，点击图片可打开原生预览
- HTTPS 站内链接会统一交给原生路由解析，覆盖公开文章、专题、合集、用户、搜索、聊天、个人中心和管理入口；正式包要自动接管浏览器链接，还需要线上 `assetlinks.json` 声明正式包名和正式签名指纹。调试包的包名/签名与生产声明不一致时，系统会显示链接选择器，这是预期行为
- 文章详情评论：一级评论、回复、@用户候选插入、图片/文件附件、点赞、举报、本人/管理员删除，以及评论通知定位后的短暂高亮
- 我的、内容管理、账号隐私和 AI 助手入口
- 个人工作台：文章状态、消息待办、群聊、内容表现和管理员举报摘要；管理员可从管理待办进入系统概况
- 管理员系统概况：通过 `/admin/system/status` 读取应用、MySQL、Redis、存储、备份、可靠性和轻量监测状态；支持确认后调用 `/admin/system/backups` 立即生成数据库备份并刷新列表；支持 `/admin/system` HTTPS 深链，未登录和非超级管理员分别显示登录/权限提示

## 可选的 FCM 后台推送配置

FCM 是可选能力。Firebase 配置为空时，APK 仍可正常构建和运行，只使用登录后的前台通知轮询；配置完整后，Android 会把 FCM token 注册到 `/api/push/native-subscriptions`，服务端通过 Firebase HTTP v1 发送后台数据消息。

服务端只读取以下环境变量，服务账号私钥不要放进 APK、网页或仓库：

```text
FCM_PROJECT_ID=<Firebase 项目 ID>
FCM_CLIENT_EMAIL=<服务账号 client_email>
FCM_PRIVATE_KEY=<服务账号 private_key，可用 \n 表示换行>
```

先在 API 数据库执行 Prisma 迁移，再重启 API。Android 构建时传入 Firebase Android 应用的公开配置：

```powershell
.\gradlew.bat :prototype:assembleDebug `
  -PfirebaseApiKey=<Firebase Web/API key> `
  -PfirebaseProjectId=<Firebase 项目 ID> `
  -PfirebaseApplicationId=1:<项目编号>:android:<应用标识> `
  -PfirebaseSenderId=<Firebase 项目编号>
```

`firebaseApiKey`、项目 ID、应用 ID 和 sender ID 只是客户端初始化参数，不等同于服务账号私钥；生产环境仍应使用正式签名证书和正式包名重新构建。后台推送的真实到达、点击路由和 token 注销需要在已登录设备、Firebase 项目和服务端凭据都配置后验收。
